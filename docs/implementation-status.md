# Стан платформи УО-6

Опубліковано: https://gsse.work/testing/
Код застосунку: commit `74945e6`, інтегрований у локальну `main`.

## Працює

- Український інтерфейс на комп’ютері та телефоні.
- 20 іспанських запитань із документа, по 4 варіанти.
- Серверні спроби, 20 секунд на запитання, захист від повторного старту.
- Тимчасовий кабінет викладача `admin@student.karazin.ua` з окремим паролем.
- Перегляд тесту з видимим таймером без збереження навчальних результатів.
- Список спроб, фільтри, детальні відповіді, CSV і перевірка ключів.
- SQLite, окремий systemd-сервіс, щоденне резервне копіювання на VPS.

Пароль міститься тільки в локальному `.credentials/teacher-access.txt`
із правами 0600. Файл ігнорується Git. У базі зберігається лише scrypt-хеш.

## Що ще потребує даних власника

Для реального входу студентів потрібні Google OAuth client ID / secret,
налаштований callback і перевірка навчального Workspace. Код готовий,
але без цих даних Google-вхід вимкнений. Тест закрито для студентів.
Перед відкриттям викладач також підтверджує уточнення ключів №7, №10, №16.

## Перевірки

- 38 перевірок пройдено, включно з двома браузерними регресіями.
- Окремо перевірено настільний і мобільний вигляд, повний перегляд 20 запитань,
  закінчення часу, результат і вихід.
- Студентський сценарій на ізольованій тестовій базі: оновлення сторінки
  не поновлює час; відновлення інтернету повертає актуальне запитання.
- Реальний VPS: HTTPS, парольний вхід, CSV, українські екрани, таймер;
  перезапуск сервісу зберігає сесію; backup відновлено в окрему тимчасову
  базу й перевірено цілісність і наявність облікового запису викладача.
- Наявні сайт та API `gsse.work` продовжують відповідати успішно.

## Рішення та межі

- За запитом користувача застосунок розміщено на його VPS у `/testing/`.
  Якщо надалі потрібен окремий домен, необхідно змінити PUBLIC_URL і callback.
- Перегляд викладача працює окремо від справжніх спроб і не замінює
  перевірку реального Google-входу.
- Незалежний огляд виявив гонку зміни пароля, відсутність прив’язки
  Google-викладача до sub та необмежене очікування запиту. Усі виправлено.
- Дві менші проблеми огляду також виправлено: стара відповідь не перезаписує
  cookie після входу; таймер віднімає час проходження запиту. На повільній
  мережі показаний час може бути трохи консервативним; рішення приймає сервер.
- Фактичні Google Workspace claims неможливо перевірити без OAuth-підключення.
  Сумісність CSV з усіма табличними редакторами не перевірялася; застосовано
  стандартне екранування полів та захист від формул.
- Резервні копії зберігаються на тому самому VPS, тому не захищають від
  втрати всього сервера.
